# 建模参数表

> **本表不需要 Blender 即可填写交付；填完即为可交产物。**
> 用法：与 `asset_list.md` 一一对应，一个资产一行。**参数要能给到建模的人直接照着做**。

## 一 全局约定

| 项 | 值 |
|---|---|
| 单位 | 【填】米（Blender 默认 1 unit = 1 m） |
| 朝向 | 【填】+Y up（导出时）；Blender 内 -Y 朝前 |
| 缩放 | 【填】`Ctrl+A → Scale` 必须应用（1.0,1.0,1.0） |
| 变换 | 【填】原点在世界中心 / 物体底部 / 轴心 |
| 三角化 | 【填】导出前三角化（glTF 必须） |

## 三 材质与贴图

| 项 | 填写 |
|---|---|
| 贴图尺寸 | 【填】2048×2048（主体）/ 1024（小件） |
| 贴图类型 | 【填】BaseColor + Normal + ORM（R=AO/G=Rough/B=Metal） |
| 是否共用图集 | 【填】是 / 否；若共用，列出同图集资产 |
| 透明 | 【填】无 / Alpha Clip / Alpha Blend（**移动端尽量不用 Blend**） |

## 四 建模要点（给动手的人）

1. **先做 blockout 再细化**：比例对不上时，细化越细返工越大
2. **保持四边面**，只在硬表面棱边加支撑线；导出前统一三角化
3. **法线**：硬表面用自定义法线或加权重法线，别直接 Shade Smooth
4. **UV**：接缝放在背面或不常看的一侧；贴图密度各资产之间尽量一致
5. **命名与集合**：按 `naming_export.md` 的前缀分集合，方便一次选中导出
