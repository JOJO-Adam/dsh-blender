# 命名与导出规范

> **本表不需要 Blender 即可填写交付；填完即为可交产物。**
> 用法：先定命名前缀，再核对导出参数。**导出的东西别人要能一次导进去，参数必须写全**。

## 一 命名规则

```
<前缀>_<主体名>_<变体/尺寸>[_LOD<级别>]
例：SM_Sword_Proxy_01        ENV_Room_Corner_4x4_01_LOD1
```

| 项 | 规则 |
|---|---|
| 前缀 | 【填】`SM_`（道具）/ `ENV_`（环境）/ `CH_`（角色）/ `MAT_`（材质）/ `T_`（贴图） |
| 大小写 | 【填】全大写主体 + 首字母大写变体（**不用中文、不用空格**） |
| 分隔符 | 【填】下划线 `_`，不用 `-`、不用 `.` |
| 变体编号 | 【填】两位数字 `01` 起 |
| LOD 后缀 | 【填】`_LOD0/_LOD1/...`，**LOD0 是最高精度** |
| 禁止 | 【填】`final`、`最终版`、`copy`、`new`、个人缩写 |

## 二 导出参数（glTF / glb）

| 参数 | 值 | 为什么 |
|---|---|---|
| 格式 | 【填】`.glb`（单文件）/ `.gltf + .bin + 贴图` | 【填】glb 便于分发，gltf 便于改 |
| +Y up | 【填】**开启**（Apply +Y up） | 引擎与 glTF 标准都是 Y 轴向上 |
| 单位 | 【填】米（Scale 1.0） | 【填】Unity/UE 导入时按 1 米对应 |
| 应用变换 | 【填】**导出前必做**（位置/旋转/缩放归零） | 否则引擎里尺寸错乱 |
| 三角化 | 【填】开启 | glTF 只支持三角面 |
| 法线 | 【填】导出 | 【填】不做则引擎自己算法线，硬表面会脏 |
| 切线 | 【填】开启（有法线贴图时必须） | 无法线贴图则不需要 |
| 动画 | 【填】含 / 不含 | 【填】角色含骨骼动画，道具不含 |
| 材质 | 【填】导出 Principled BSDF → PBR | 【填】复杂节点树不会被导出 |
| 贴图 | 【填】嵌进 glb / 单独放 textures/ | 【填】 |
| 压缩 | 【填】不压缩 / Draco（注明需引擎支持） | 【填】Draco 能小 60%，但部分旧引擎不支持 |

## 三 交付文件结构

```
【填】包名/
  ├─ source/                    # 源文件
  │   └─ 【填】包名.blend
  ├─ export/
  │   ├─ 【填】SM_xxx.glb
  │   └─ 【填】CH_xxx.glb
  ├─ textures/
  │   └─ 【填】T_xxx_basecolor.png
  └─ docs/
      ├─ asset_list.md / model_spec.md
      ├─ naming_export.md / delivery_checklist.md
      └─ preview_01.png（预览图）
```

**规则**：源文件与导出物**分开放**；贴图单独目录；文档随包；**不要出现 `新建文件夹`、`副本`**。

## 四 导出后必做的三件

1. **重新导入一次**（New File → Import glTF），确认能读、尺寸与朝向正确
2. **检查材质是否丢**（贴图路径、Principled 参数）
3. **量一下面数与包围盒**，与 `model_spec.md` 的上限对齐
