# UV 展开打包工序单（标记缝合边 → 展开 → 打包优化）

> 本表不需要 Blender 即可填写交付（执行工序时才开 Blender）。旧链路只给结论不给「怎么办」，本单是工序级配方。

## 1. 工序（按序执行，不许跳步）

| 步 | 动作 | 操作（Blender） | 自检 |
|---|---|---|---|
| 1 | 标记缝合边 | Edit 模式选边 → Mark Seam；曲面按参数方向切（如旋转体沿经线切一刀+收口环切） | 岛数与预期一致（复杂曲面 ≥3 岛） |
| 2 | 展开 | 全选面 → UV → Unwrap（ANGLE_BASED；参数规整面可直接按参数矩形化铺 UV） | 每岛无拉伸（UV 边长比接近 1） |
| 3 | 打包优化 | UV → Pack Islands（勾 Blend/Margin；栅格化曲面片做矩形化填满格子） | 打包率过验收线（见 §2） |
| 4 | 去重叠 | Pack 后查重叠：栅格化统计重叠格数 | 重叠栅格 = 0 |

## 2. 验收线（写死，不许放宽）

| 判据 | 阈值 | 出处 |
|---|---|---|
| 打包率（UV 占用面积/图集面积） | **> 0.75** | 判据范式 C1（旧链路 ANGLE_BASED 直展实测仅 0.575；矩形化后 0.91） |
| 重叠栅格（512² 栅格化） | **= 0** | C1「无重叠」 |
| UV 面积/3D 面积比 | 0.85 ~ 1.15 | T2.4 判据范式 |
| UV 边长比（mean/mean） | ≈ 网格整体比例（0.2~0.4 量级） | T2.4 判据范式 |
| 逐面 UV 无重叠（per-face pair） | **0 对重叠** | T2.4 判据范式 |

## 4. 常见翻车

- 只 Unwrap 不 Pack Islands → 打包率掉到 0.5x（实测 0.575）。
- 缝合边不闭合 → 岛粘连、局部拉伸。
- 曲面片直展只填满包围盒 ~79% → 参数矩形化铺满格子（margin 0.0015）。
