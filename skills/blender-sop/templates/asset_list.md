# 资产清单表

> **本表不需要 Blender 即可填写交付；填完即为可交产物。**
> 用法：一行一个资产，先填「资产名 / 类型 / 用途」，再按用途给面数预算与命名。
> 填完连同 `model_spec.md` / `naming_export.md` / `delivery_checklist.md` 一起交付。

## 一 项目基本信息

| 项 | 填写 |
|---|---|
| 项目 / 包名 | 【填】如 `lowpoly_props_pack_01` |
| 交付形态 | 【填】单个 blend / glTF + 贴图 / 两者都要 |
| 目标平台 | 【填】Unity / Unreal / 网页 / 移动端 |
| 渲染风格 | 【填】low-poly / 写实 / 卡通 |
| 单位约定 | 【填】1 单位 = 1 米（默认） |

## 三 类型说明（照这个口径填，别自己造）

| 类型 | 前缀 | 典型面数 | 是否含骨骼 |
|---|---|---|---|
| 道具（Prop） | `SM_` | 100–2000 | 否 |
| 环境（Environment） | `ENV_` | 500–20000 | 否 |
| 角色（Character） | `CH_` | 3000–50000 | 是 |
